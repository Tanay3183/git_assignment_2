# GitHub Features

1. Repositories – Host and manage project source code.
2. Branches – Work on features independently from the main branch.
3. Pull Requests – Propose and review changes before merging.
4. Issues – Track bugs, enhancements, and tasks.
5. Actions – Automate workflows using CI/CD pipelines.
6. Projects – Organize and manage work using boards.
7. Releases – Publish versions of software with release notes.
8. Discussions – Community conversations around projects.
